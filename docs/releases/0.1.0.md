First public version of GPSLoggerKitGPL: file formats and logger protocols ported from GPL-licensed sources
(gpsbabel 1.7.0, igotu2gpx 0.3.0), built on [GPSLoggerKit](https://github.com/mytracks/GPSLoggerKit) 0.1.x. This is an
early release (pre-release): the API may still change in 0.x minor versions.

**Platform:** macOS 12+ · Swift 6 · license GPL-3.0-or-later (any app using it is covered by the GPL as a whole)

**File formats (read):** SkyTraq memory dump, MTK and Holux memory dumps (`mtk-bin`, `m241-bin`), Wintec TES / TK1 /
memory dump, Locosys SBP / SBN, Medion GoPal (`.trk`), Magellan (`.log`, `.upt`, `.rte`), Alan Map500 (`.trl`).

**Logger protocols:** SkyTraq Venus, MTK / Holux (M-241, GPSport 245), Wintec WBT-100/200/201, G-Rays 2, WSG-1000,
Locosys Navilink, Magellan Meridian / SporTrak / eXplorist, XAiOX iTrackU, i-GotU (GT-100/120/200/200e/600 over
USB-HID, GT-800/Pro serial; erasing is experimental). Transports are provided by the app through `DeviceConnection`.

Installation (macOS only):

```swift
.package(url: "https://github.com/mytracks/GPSLoggerKitGPL.git", .upToNextMinor(from: "0.1.0"))
```

`PROVENANCE.md` lists the template, authors and license of every ported format; ported files carry the notices of
their templates.
